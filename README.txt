Autonomous Drone Project

Features:
- Autonomous Takeoff and Mission Execution
- KML-Based Waypoint Loading
- Real-time Object Detection & Survivor Geotagging
- Speaker Activation and Payload Delivery
- Fail-safes and State Machine Control
- Flask-based Dashboard for Mission Monitoring

To Run:
1. Ensure drone SDK and hardware are configured.
2. Install Python dependencies (cv2, dronekit, Flask, etc.)
3. Execute main.py to begin mission simulation.
